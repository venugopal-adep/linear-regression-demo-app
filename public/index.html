The Math Behind Linear Regression

1. The Linear Model

Linear regression models the relationship between a dependent variable \(y\) and one or more independent variables \(x\) using a linear equation:

\[y = mx + b\]

Where:

  • \(m\) is the slope (the change in \(y\) for a unit change in \(x\))
  • \(b\) is the y-intercept (the value of \(y\) when \(x = 0\))

2. Finding the Best Fit Line - Analytical Solution

In this application, we use the Ordinary Least Squares (OLS) method to find the optimal values for slope and y-intercept directly, rather than using an iterative approach like gradient descent.

The Cost Function

We want to minimize the sum of squared differences between the observed values and the values predicted by the line:

\[J(m,b) = \sum_{i=1}^{n} (y_i - (mx_i + b))^2\]

This is called the Sum of Squared Errors (SSE) or Residual Sum of Squares (RSS).

Deriving the OLS Formulas

To find the values of \(m\) and \(b\) that minimize the cost function, we take the partial derivatives with respect to each parameter and set them equal to zero:

Step 1: Find the partial derivative with respect to \(b\):

\[\frac{\partial J}{\partial b} = -2\sum_{i=1}^{n} (y_i - (mx_i + b)) = 0\]

Step 2: Find the partial derivative with respect to \(m\):

\[\frac{\partial J}{\partial m} = -2\sum_{i=1}^{n} x_i(y_i - (mx_i + b)) = 0\]

Step 3: Solving for \(b\) from the first equation:

\[\sum_{i=1}^{n} (y_i - mx_i - b) = 0\]
\[\sum_{i=1}^{n} y_i - m\sum_{i=1}^{n} x_i - nb = 0\]
\[b = \frac{\sum_{i=1}^{n} y_i - m\sum_{i=1}^{n} x_i}{n} = \bar{y} - m\bar{x}\]

Where \(\bar{x}\) and \(\bar{y}\) are the means of the \(x\) and \(y\) values respectively.

Step 4: Substituting this expression for \(b\) into the second equation and solving for \(m\):

\[\sum_{i=1}^{n} x_i(y_i - mx_i - (\bar{y} - m\bar{x})) = 0\]
\[\sum_{i=1}^{n} x_i y_i - m\sum_{i=1}^{n} x_i^2 - \bar{y}\sum_{i=1}^{n} x_i + m\bar{x}\sum_{i=1}^{n} x_i = 0\]

Noting that \(\sum_{i=1}^{n} x_i = n\bar{x}\), we can simplify:

\[\sum_{i=1}^{n} x_i y_i - m\sum_{i=1}^{n} x_i^2 - n\bar{x}\bar{y} + mn\bar{x}^2 = 0\]

Rearranging to solve for \(m\):

\[m = \frac{\sum_{i=1}^{n} x_i y_i - n\bar{x}\bar{y}}{\sum_{i=1}^{n} x_i^2 - n\bar{x}^2}\]

This can be rewritten as:

\[m = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}\]

Or in the form we implement in our code:

\[m = \frac{n\sum_{i=1}^{n} x_i y_i - \sum_{i=1}^{n} x_i \sum_{i=1}^{n} y_i}{n\sum_{i=1}^{n} x_i^2 - (\sum_{i=1}^{n} x_i)^2}\]

Key Difference from Gradient Descent

Unlike gradient descent, which iteratively updates the parameters to converge to the minimum, OLS provides a direct analytical solution. For simple linear regression, OLS is computationally efficient because:

  • It requires a single calculation rather than multiple iterations
  • It guarantees the global minimum of the cost function
  • It does not require selecting a learning rate or other hyperparameters

However, for more complex models or very large datasets, iterative methods like gradient descent can be more practical.

3. Evaluating the Model

R² Score (Coefficient of Determination)

R² measures the proportion of variance in the dependent variable that is predictable from the independent variable:

\[R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2}\]

Where:

  • \(\hat{y}_i\) is the predicted value for \(y_i\)
  • \(\bar{y}\) is the mean of all \(y\) values

R² ranges from 0 to 1, with higher values indicating better fit.

Mean Squared Error (MSE)

MSE measures the average of the squares of the errors:

\[MSE = \frac{1}{n}\sum_{i=1}^{n} (y_i - \hat{y}_i)^2\]

Lower MSE values indicate better fit.
